# Primi passi

Benvenuti nella guida interna del PIM. Questa sezione raccoglierà le informazioni di base per orientarsi nel pannello: come accedere, come si organizza il menu, i concetti principali (prodotti, tassonomie, listini, lingue).

Questa è una pagina di esempio, creata per verificare che il meccanismo della wiki funzioni — albero di navigazione, rendering Markdown, ricerca testuale. I contenuti reali verranno scritti in un secondo momento, pagina per pagina.
