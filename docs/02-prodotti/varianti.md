# Varianti

Come funzionano le varianti di prodotto nel PIM.

Pagina di esempio, usata per verificare che una sezione possa contenere più pagine ordinate tra loro tramite il campo `order` nel front matter.

| Colonna | Significato |
| --- | --- |
| SKU variante | Codice univoco della singola variante |
| Attributi | Combinazione di valori (es. colore, taglia) che identifica la variante |

Una tabella Markdown, per verificare che l'estensione `TableExtension` di CommonMark sia attiva.
