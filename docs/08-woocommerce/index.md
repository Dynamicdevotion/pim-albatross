# WooCommerce

Documentazione della sincronizzazione con WooCommerce (modulo WooSync).

Questa sezione compare nella guida **solo** quando il modulo WooSync è attivo per l'installazione (`WOOSYNC_ENABLED=true`) — è l'esempio usato per verificare la visibilità condizionale delle sezioni: se il cliente non ha acquistato l'add-on WooSync, questa voce sparisce dal menu della wiki.
